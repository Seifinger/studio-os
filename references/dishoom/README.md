# Referenz: Dishoom (nur lokal)

Qualitätsmaßstab für atmosphärische Restaurant-Websites – **keine Vorlage**. Screenshots und die
Bildschirmaufnahme bleiben auf dem Rechner des Studios (`.gitignore`), weil sie fremdes Material
enthalten. Im Repository steht nur die abstrakte Auswertung:
[`docs/design-studies/dishoom-analysis.md`](../../docs/design-studies/dishoom-analysis.md).

| Datei (lokal) | Inhalt |
|---|---|
| `screenshots/*.png` | vier Mobil-Screenshots des Inhabers (Eröffnung, Karte, Erzählteil, Bild mit Bildunterschrift) |
| `frames/frame-01.png` … `frame-25.png` | ein Bild pro Sekunde aus der Mobil-Aufnahme (25 s, 23.09.2026) |
| `frames/sheet-*.png` | Kontaktbögen je fünf Bilder |

Eine `notes.md` mit eigenen Beobachtungen lag nicht vor; die Beobachtungen stehen in der Analyse.
